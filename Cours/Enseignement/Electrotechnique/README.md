# ⚡ Électrotechnique

Modèles 3D pour le cours d'électrotechnique.

## 📦 Modèles disponibles

Ajoutez vos modèles 3D ici. Chaque modèle doit avoir 2 formats :

- **`.glb`** → Android
- **`.usdz`** → iOS

## 📁 Organisation suggérée

```text
Electrotechnique/
├── Transformateurs/
│   ├── transformateur-monophase.glb
│   ├── transformateur-monophase.usdz
│   ├── transformateur-triphase.glb
│   └── transformateur-triphase.usdz
│
├── Moteurs/
│   ├── moteur-asynchrone.glb
│   ├── moteur-asynchrone.usdz
│   ├── moteur-synchrone.glb
│   └── moteur-synchrone.usdz
│
└── Generateurs/
    ├── alternateur.glb
    └── alternateur.usdz
```

## 🎯 Exemples de modèles à créer

- Transformateurs (monophasé, triphasé)
- Moteurs électriques (asynchrone, synchrone, DC)
- Générateurs et alternateurs
- Disjoncteurs et protections
- Contacteurs et relais
- Condensateurs
- Bobines et inductances
- Tableaux électriques
