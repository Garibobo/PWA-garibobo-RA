👆 Gestes et commandes

📱 Smartphone et tablette

  • ☝️ 1 doigt : tourner le modèle
  • 🤏 Pincer à 2 doigts : zoomer sur le modèle
  • ✌️ Glisser à 2 doigts : déplacer le modèle
  • 🔍 Pincer hors du lecteur : zoomer la page

💻 Ordinateur

  • 🖱️ Clic gauche + glisser : tourner
  • 🖱️ Molette : zoomer
  • 🖱️ Clic droit + glisser : déplacer
  • ⌨️ Flèches du clavier (après un clic sur le modèle) : tourner

🥽 Réalité augmentée

  • ☝️ 1 doigt : déplacer le modèle sur le sol ou le mur
  • ✌️ 2 doigts : tourner et changer la taille
  • 📏 En RA Web (Android) : boutons Dimensions et 1:1 Taille réelle à gauche
